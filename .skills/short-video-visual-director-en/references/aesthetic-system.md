# Aesthetic System

Choose one primary family and no more than one accent. A style name is a production preset that constrains palette, light, material, subject, composition, and movement together.

| Family | Read | Typical attributes |
|---|---|---|
| Ethereal / divine | weightless, luminous, soft | clouds, shafts of light, negative space, slow push, floating particles |
| Hyperpop / Y2K | glossy, neon, digital | chrome, jelly surfaces, saturation, sudden speed bursts |
| Dark / mysterious | tense, dangerous, grainy | deep black, hard contrast, isolated source, handheld motion |
| Retro / print | graphic, nostalgic, flat | halftone, collage, old ads, restricted palette |
| Organic / tactile | intimate, natural, macro | fabric, liquid, skin, plants, close detail |
| Systemic / data | ordered, technical, abstract | grids, pixels, heatmaps, numbers, diagrams |

## Visual Bible Fields

Primary/accent style; base/accent/danger colors and ratios; key-light direction, hardness, temperature, and contrast; grain, sharpness, bloom, aberration, and surface; shot scale, center of gravity, and negative space; allowed camera moves and speeds; typography hierarchy and safe area; transitions, sound triggers, and explicit do-not rules.

## Original angelcore × cloud-trance preset

Use only when the user wants the original `taste` direction: near-black and bone white base; molten-gold/ember light in dark frames; violet–cyan–magenta crystalline iridescence in bright frames; one accent per shot. Add grain and subtle aberration to dark frames, clean gloss to bright frames. Favor drift, slow push, and orbit; reserve speed for the drop. Signature grammar: beat-locked cuts, macro hero objects on black, bloom reveals, one-color punches inside monochrome, and a speed ramp into the climax.

This preset never overrides user references or brand rules.
