# Verdict Template

```markdown
## Decision Council: Short title

**Question:** One normalized decision
**Constraints:** Material constraints
**Success criteria:** Observable criteria

### Raw positions
**Architect:** Position
- Key reason
- Biggest risk
- Surprise

**Skeptic:** Same structure
**Pragmatist:** Same structure
**Critic:** Same structure

### Verdict
- **Consensus:** Where the voices align
- **Strongest dissent:** The most important disagreement
- **Premise check:** Whether the framing or assumptions should change
- **Recommendation:** The selected path and rationale
- **Switch conditions:** New facts that would change the recommendation
- **Next action:** One concrete, reversible step
```
