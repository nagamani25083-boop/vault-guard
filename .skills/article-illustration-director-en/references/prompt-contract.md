# Shot and Prompt Contract

```json
{
  "insert_after": "section heading or passage excerpt",
  "theme": "English topic",
  "core_message": "one core message",
  "composition_pattern": "breakpoint/branching/loop/compare/input-output/layer/evidence/state",
  "character_action": "one simple action",
  "elements": ["2–5 visual elements"],
  "labels": ["1–4 short labels"],
  "prompt_en": "complete production prompt",
  "negative_prompt": "failure modes to exclude",
  "aspect_ratio": "16:9"
}
```

Prompt order: `editorial purpose + visual metaphor + character and action + layout + objects + style DNA + palette + labels + aspect ratio + continuity anchors + exclusions`.

Require a white background, clean charcoal lines, restrained local color, generous negative space, simple hands, one core structure, no upper-left category title, no slideware, no dense architecture, no unreadable text, and no extra fingers. Keep labels to one–four short terms; render critical text as an application overlay.
