# Composition Patterns

| Pattern | Use | Visual action |
|---|---|---|
| Breakpoint | failed processes or broken chains | The observer inspects a broken pipe, bridge, or log stream. |
| Branching | conditions, choices, routing | One path separates into a few clear branches. |
| Loop | feedback, iteration, training | Information returns to the start and changes the state. |
| Before–after | remediation or method upgrades | Two states of the same character or system. |
| Input–output | toolchains and transformation | A readable device transforms input into output. |
| Layer cutaway | stacks, permissions, system layers | A few clear layers, never a dense architecture diagram. |
| Evidence board | review, reasoning, related clues | The observer organizes logs, evidence, and a few links. |
| State instrument | progress, health, risk | One tangible instrument reflects a state change. |

Invent the metaphor from the current article. Use one primary pattern and at most two or three supporting element groups.
