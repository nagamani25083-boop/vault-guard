# Integration and acceptance

1. Create a real login flow and execute assets/schema.sql in the application Supabase instance. Authenticated users have read-only access to their own jobs. The private kling-audio storage bucket has no public access policy.
2. Deploy edge.ts as index.ts together with core.mjs and media-policy.mjs to the kling-audio Edge Function. Dependency: npm:@supabase/supabase-js@2. Validate the import and build in the actual target runtime.
3. Configure server-only SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, INTEGRATIONS_API_KEY, APP_ORIGIN. APP_ORIGIN is the actual app origin. MEDIA_HOSTS is optional for private transfer only, and is a comma-separated exact hostname allowlist established from real provider media results; do not invent wildcard domains. Redirects are refused.
4. Use audioClient(supabase) from assets/client.js. On an explicit user submission, create and retain one crypto.randomUUID(). Call api.call({action:'create', id, kind:'text', params:{prompt:'Ocean waves breaking on a beach',duration:5}}). Then api.watch(id, task=>api.render(container,task), signal). Abort on unmount; only one watcher per task. Keep the task ID across refreshes and restore history using action:list.
5. On success immediately render original media. Do not automatically call save. Show private save only when can_save is true. A failed save must not restart generation. Signed links last ten minutes; obtain refreshed links through an owned query/list/save request. Handle media load failures visibly.
6. For video input, inspect MIME/container, byte size and measured duration before submission; the provider remains the final validator. The default reference checks video_id against the current user's recorded video outputs. Videos from another platform skill require a trusted owner/source mapping; until then use the user's uploaded video URL.
7. Generation-time operator usage: python3 scripts/upstream_task.py create --receipt /private/path/job.json --kind text --params '{"prompt":"Ocean waves","duration":5}'. Then query the same receipt. The script does not expose account list queries. Operator receipts and result URLs must stay private. Never mount this script as an unauthenticated app API.
8. The supplied app path provides playback/download/private save. Operator task completion must likewise download or save the returned media before claiming file delivery; a task ID or unverified URL alone is not completion.

## Known implementation boundaries
The Edge reference buffers up to 32 MiB per media file with a 20-second download budget. Larger files need a verified background/streamed transfer worker. Its five-second poll cadence and 30-second query lease are app defaults, not provider rate-limit guarantees. User-level quotas and concurrent creation limits must be configured using the actual platform facilities before public release.
A timed-out create is stored as outcome uncertain. Do not repeat it automatically. Reconcile via the provider's verified custom-ID query protocol; that protocol's exact encoding remains unspecified in the supplied pages.
The four overseas backend API IDs are mapped in references/api.md and both calling implementations. Use the platform gateway runtime and X-Gateway-Authorization; never reuse domestic IDs or provider credentials. Live gateway and QA acceptance remain pending.

## Required QA tests
Validate text boundaries 3/10 seconds and 200 characters, excessive length, empty text, mutually exclusive video inputs and boolean ASMR. Test business errors, submitted→processing→succeed, failed, unknown state, ID mismatch and empty media. Verify A creates/B queries or saves returns 404; B's history excludes A; unauthenticated calls return 401; direct user table writes fail; private media access fails without a signed URL. Verify same-ID duplicate creation does not repeat POST, page refresh resumes, playback/download works and save retry does not regenerate. Run real text and video inputs separately.
Offline syntax or unit checks are not evidence of live upstream, database isolation, overseas QA or media playback success.
