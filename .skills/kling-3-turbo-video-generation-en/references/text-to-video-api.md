## Request Body

```json
{
  "prompt": "A girl sat on the train, looking out the window with a melancholic expression.",
  "settings": {
    "duration": 3,
    "resolution": "720p",
    "aspect_ratio": "9:16"
  },
  "options": {
    "callback_url": "https://example.com/callback",
    "external_task_id": "unique-task-id",
    "watermark_info": { "enabled": false }
  }
}
```

## Parameters

- `prompt`: required string, maximum 3072 characters; maximum 2500 is recommended;
- `settings.resolution`: optional, `720p` or `1080p`, default `720p`;
- `settings.aspect_ratio`: optional, `16:9`, `9:16`, or `1:1`, default `16:9`;
- `settings.duration`: optional integer from 3 to 15, default 5;
- `options.callback_url`: optional callback URL;
- `options.external_task_id`: optional; must be unique within one user account;
- `options.watermark_info.enabled`: optional boolean, default `false`;
- custom watermarks are not supported;
- do not add a `model` field.

## Prompt-Based Multi-Shot Format

```text
shot 1, 2, A wide shot of a railway platform; shot 2, 3, A close-up of the girl looking through the window;
```

Rules:

- 1 to 6 shots;
- each shot duration is at least 1 second;
- the sum of shot durations equals `settings.duration`;
- each `words` segment is at most 512 characters;
- use half-width semicolons;
- submit the entire multi-shot description as the ordinary `prompt` string;
- do not add `multi_shot`, `shot_type`, or `multi_prompt` fields.

Use `data.id` as the system task ID. Do not read `data.task_id`.

## Complete Asynchronous Example

```typescript
const createEndpoint =
  "https://app-f58c4fdcbbpd-api-l9nZxREvJ6V9.gateway.appmedo.com/text-to-video/kling-3.0-turbo";
const queryEndpoint =
  "https://app-f58c4fdcbbpd-api-GaDwzVOqmRNY.gateway.appmedo.com/tasks";
const apiKey = process.env["INTEGRATIONS_API_KEY"]!;
const externalTaskId = `overseas-text-${crypto.randomUUID()}`;

const createResponse = await fetch(createEndpoint, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Gateway-Authorization": `Bearer ${apiKey}`,
  },
  body: JSON.stringify({
    prompt: "A girl sat on the train, looking out the window.",
    settings: { duration: 5, resolution: "720p", aspect_ratio: "16:9" },
    options: {
      external_task_id: externalTaskId,
      watermark_info: { enabled: false },
    },
  }),
});

const createJson = await createResponse.json();
if (!createResponse.ok || createJson.code !== 0) {
  throw new Error(`Create failed: ${createJson.message ?? createResponse.status}`);
}
const taskId = String(createJson.data.id);

while (true) {
  const queryResponse = await fetch(
    `${queryEndpoint}?task_ids=${encodeURIComponent(taskId)}`,
    {
      headers: {
        "Content-Type": "application/json",
        "X-Gateway-Authorization": `Bearer ${apiKey}`,
      },
    },
  );
  const queryJson = await queryResponse.json();
  if (!queryResponse.ok || queryJson.code !== 0) {
    throw new Error(`Query failed: ${queryJson.message ?? queryResponse.status}`);
  }

  const task = queryJson.data.find(
    (item: { id: string }) => String(item.id) === taskId,
  );
  if (!task) throw new Error("Target task was not found");
  if (task.status === "failed") {
    throw new Error(task.message || "Video generation failed");
  }
  if (task.status === "succeeded") {
    const output = task.outputs?.find(
      (item: { type: string }) => item.type === "video",
    );
    if (!output?.url) throw new Error("Successful task has no video output");
    console.log(output.url);
    break;
  }
  await new Promise((resolve) => setTimeout(resolve, 7000));
}
```

Persist successful video output before returning the final application result. Use `task.id + output.id` as the transfer idempotency key; retry transfer without creating another generation task.

Do not expose server credentials in frontend code. Generated applications must perform creation and querying through server-side Edge Functions.
